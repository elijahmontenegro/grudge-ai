== Context

=== Identity

*Name:* {project-name} {module-name}

*Paradigm:* Stateless RRC Proxy + System Tray Service

The RRC service is the engine that implements {rrc-full}. It runs as a background process in the OS system tray and exposes two interfaces:

1. **LLM Proxy** -- An HTTP endpoint that accepts standard LLM API requests. Clients send full conversation history as they normally would. The service intercepts, selects prerequisites, assembles the payload, forwards to the actual LLM, parses the response stream, and caches reasoning for warm carry-forward. The client does not change. The model does not know.

2. **GraphQL API** -- A query interface for the agentic tool (and any privileged client) to access RRC introspection data: what was selected, what was excluded, prerequisite scores, prompt derivation, carry-forward state.

=== Scope

==== In Scope

- RRC engine: prerequisite detection, selection scoring, payload assembly, native format restoration, bounded assembly
- Warm carry-forward: response stream parsing, reasoning content extraction, carry-forward cache, selection enrichment
- LLM proxy: HTTP endpoint accepting standard LLM API requests, transparent forwarding
- Embedding pipeline: embed conversation messages using core embedder interface
- GraphQL API: schema and resolvers for RRC introspection (selection results, scores, exclusions, prompt derivation)
- System tray integration (Windows primary, cross-platform later)
- Service lifecycle: start, stop, health check, configuration
- Serving the agentic tool's static assets (Web UI)

==== Out of Scope

- Conversation storage (the client owns its corpus; RRC receives it per-request)
- Upstream summarization or entity extraction (violates lossless corpus property)
- LLM interface or provider adapter definitions (belongs to `spec/core`)
- Embedder interface or adapter definitions (belongs to `spec/core`)
- Agentic UI, tool visualization, or interaction patterns (belongs to `spec/agent`)
- Agent orchestration / agent loop (belongs to `spec/agent`)
- Provider-specific preferential treatment
