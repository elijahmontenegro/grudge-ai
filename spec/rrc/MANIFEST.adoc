== Context

=== Identity

*Name:* {project-name} {module-name}

*Paradigm:* Pure Algorithm Library

The RRC engine is a Go library implementing the {rrc-full} algorithm. It is pure logic with no opinions about HTTP, deployment, UI, or orchestration. Given a conversation corpus and a prompt, it returns the selected prerequisite messages for coherent continuation.

The service imports this library. The engine does not know it runs inside a proxy.

*Language:* {lang}

*Dependencies:* `spec/core` (truth types, embedder interface)

=== Scope

==== In Scope

- Prerequisite detection algorithm: identifying which messages the prompt depends on
- Selection scoring: scoring model, thresholds, ranking
- Payload assembly: selecting messages, ordering, token budget, bounded assembly
- Native format restoration: outputting selected messages as standard conversation entries
- Warm carry-forward: accepting reasoning content from parsed responses, enriching future selection
- Embedding pipeline: embedding conversation messages via core embedder interface

==== Out of Scope

- HTTP proxy or network concerns (belongs to `spec/service`)
- Response stream parsing (belongs to `spec/service`; the engine receives extracted reasoning)
- Agent orchestration (belongs to `spec/service`)
- Conversation storage (belongs to `spec/service`)
- LLM interface or provider adapters (belongs to `spec/core`)
- Embedder interface or adapter definitions (belongs to `spec/core`)
- UI or introspection presentation (belongs to `spec/web`)
